# Getting Started — Game Engine for Teaching

> **Goal:** Get from a fresh clone to a running 3D scene in about 5 minutes.
> You will need Visual Studio 2022 (Desktop C++ workload) and Python 3.9+.

---

## Step 1 — Clone the Repository

```bash
git clone https://github.com/Mikester9000/Game-Engine-for-Teaching-.git
cd Game-Engine-for-Teaching-
```

---

## Step 2 — Bootstrap (One Command)

Open **PowerShell** and run:

```powershell
.\scripts\bootstrap.ps1
```

This single script:
1. Bootstraps **vcpkg** at `C:\vcpkg` (skips if already present)
2. Installs Python dependencies (`pytest`, `Pillow`, etc.)
3. Configures CMake with the engine-only preset (no Qt required)
4. Builds `engine_sandbox.exe`, `cook.exe`, `pak.exe`
5. Cooks the vertical slice assets (PNG → DDS, JSON → binary)
6. Runs a headless smoke test to confirm everything works

> **Having trouble?** See `CONTRIBUTING.md` for manual build steps.

---

## Step 3 — Run the Engine

After bootstrap succeeds, the executable is in:
```
build\windows-ninja-debug-engine-only\engine_sandbox.exe
```

Try these scenes (all run headless — no GPU required, uses WARP):

```bat
:: Procedural sky with time-of-day and weather:
.\build\windows-ninja-debug-engine-only\engine_sandbox.exe --headless --scene dynamic_sky

:: PBR sphere with IBL (irradiance + prefiltered env + BRDF LUT):
.\build\windows-ninja-debug-engine-only\engine_sandbox.exe --headless --scene pbr_ibl

:: Shadow map + PCF soft shadows:
.\build\windows-ninja-debug-engine-only\engine_sandbox.exe --headless --scene shadow_test

:: Full gameplay (combat, quests, streaming) — needs windowed mode:
.\build\windows-ninja-debug-engine-only\engine_sandbox.exe --scene game
```

```
├── Animations/                               ├── Animations/
│   └── hero_run.anim.json   JSON → binary    │   └── hero_run.animc
└── Terrain/                                  └── Terrain/
    └── highland.terrain.json terrain bake         └── highland.trn

Cooked/ ──► engine_sandbox.exe (runtime loads from Cooked/ only)
```

**Source assets** live under `Content/` — edit these freely.
**Cooked assets** live under `Cooked/` — generated by `cook_assets.py`.
**Never check in** generated `Cooked/` files — they are build outputs.

## What to Try Next

### 1. Edit the Time-of-Day Settings

Open `samples/vertical_slice_project/Content/Terrain/highland.terrain.json`
and change the `cellSize` value, then re-bake with:

```bash
python tools/creation_engine.py bake-terrain \
    --input samples/vertical_slice_project/Content/Terrain/highland.terrain.json \
    --output samples/vertical_slice_project/Cooked/Terrain/highland.trn
```

Then run `--scene terrain_test` to verify the new terrain loads.

### 2. Add a New HLSL Shader

See `docs/SHADER_PIPELINE.md` for a step-by-step guide on:
- Authoring a new `.hlsl` file in `shaders/`
- Adding it to `CMakeLists.txt`'s `HLSL_SHADERS` list
- Compiling it at runtime via `D3DCompileFromFile`
- Attaching RenderDoc to inspect the result

### 3. Add a New Quest

1. Edit `samples/vertical_slice_project/Content/Quests/quest_bank.json`
   — add a new quest entry with objectives and prerequisites.
2. Bake: `python tools/creation_engine.py bake-navmesh ...` (or run the full cook)
3. Test: `engine_sandbox.exe --headless --scene quest_test`

### 4. Study a Subsystem

Every subsystem has `// TEACHING NOTE —` comments explaining *why* design decisions
were made.  Good starting points:

| What to learn | Where to look |
|---------------|---------------|
| ECS (Entity-Component-System) | `src/engine/ecs/ECS.hpp` |
| D3D11 rendering pipeline | `src/engine/rendering/d3d11/D3D11Renderer.cpp` |
| PBR shading math | `shaders/pbr_ibl.ps.hlsl` |
| Jolt Physics integration | `src/engine/physics/physics_world.cpp` |
| XAudio2 + 3D positional audio | `src/engine/audio/xaudio2_backend.cpp` |
| Action combat (combo FSM) | `src/engine/combat/combo_system.cpp` |
| World streaming | `src/engine/world/world_streaming.cpp` |

## Configuration

Edit `engine_config.json` (next to the `.exe`) to change settings without recompiling:

```json
{
    "resolution": { "width": 1920, "height": 1080 },
    "audio": { "masterVolume": 0.8 },
    "keys": { "attack": "Z", "dodge": "X", "jump": "Space" }
}
```

```bat
)
```
